# CalTrack

A modern calorie tracking application built with Flutter, focused on Indian users with an offline-first architecture.

> 🚧 This project is currently under active development.

## Current Features

- User authentication
- User profile management
- Weight tracking & progress visualization
- Weight history
- Daily nutrition insights
- Offline-first SQLite database
- BLoC state management

## Tech Stack

- Flutter
- Dart
- SQLite (sqflite)
- Firebase Authentication
- flutter_bloc
